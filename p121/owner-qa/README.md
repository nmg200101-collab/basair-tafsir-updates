# بصائر القرآن P121 — قناة التحديثات الشاملة (OWNER QA)

هذا المسار **قناة جديدة مستقلة** عن `p92/owner-qa-001/release.json` المحمي بالتلاوة QA-050.

## الحالة
- `release.json`: بيان **موقع RSA** مع `sequence=1` و`modules=[]`.
- **لا يحتوي على أي تعديل تطبيقي** ولا ينشر ملفات JS/CSS جديدة ولا يمس بيانات التلاوة أو التفسير.
- لا يراه التطبيق القديم؛ يحتاج المستقبل الشامل المضاف إلى مرشح APK V693 أو أحدث.
- لا يُعلن تشغيل التحديثات الحقيقية قبل تجربة V693 على هاتف المالك.

## طريقة التحديث المستقبلية
تُضاف وحدات مثل `modules/tafsir/` و`modules/hifz/` و`modules/library/` و`modules/home/`، ولكل وحدة إصدار مستقل. تُدرج بصمة SHA-256 وحجم كل ملف في بيان موقّع بمفتاح Android RSA الموجود عند المالك، وتُقدَّم عبر PR واجتياز الفحوص.

**قفل القسم المحمي:** وحدات `tilawa` و`shared` و`navigation` و`reciters` تحتاج أيضًا موافقة Ed25519 للمالك، ولا تعوق هذه الموافقة تحديثات التفسير والحفظ والمكتبة وغيرها. الشفرة التنفيذية المشتركة تحتاج دائمًا مراجعة آثارها الجانبية؛ اسم الوحدة وحده ليس عزلاً أمنياً.

**قيود:** لا يمكن تعديل Android DEX أو الأذونات أو الحزم الأصلية عن بُعد؛ يتطلب ذلك APK جديدًا. يتحقق التطبيق من RSA، وSHA-256، والتسلسل التصاعدي، والأصل الآمن، ثم يخزن الوحدات محليًا ويطبّقها بعد إعادة الفتح. يجب اختبار الرجوع على الهاتف.
