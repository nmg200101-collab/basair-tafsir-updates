# بصائر القرآن — تصحيح تطابق فهرس التفسير P118

**الحالة: ملفات على الخادم في مسار تجريبي فقط؛ غير مفعلة على هواتف المستخدمين.**

## المرجع البصري
صورة المعاينة المعتمدة سابقًا مع تعديل رأس الصفحة بحيث يظل **تنزيلات التفسير** بدل قائمة الثلاث نقاط.

## ما صُحح
- وضع نوع التفسير والمفضلة ومتابعة التفسير وآخر موضع في صف واحد، مع بحث سريع.
- البحث والانتقال إلى سورة/آية/صفحة في صف ثانٍ مختصر.
- عنوان **فهرس السور** ظاهر مع سطر توضيحي صغير.
- بطاقات السور الـ114 في قائمة رأسية بارتفاع ~46 CSS px، رقم السورة دائرة ذهبية، الاسم والآيات والصفحة، وسهم دخول جهة اليسار.
- الاحتفاظ بكافة عناصر P117 ومستمعي أحداثها؛ لا نسخ مكررة من عمليات الانتقال أو حذف لأي مصادر تفسير.
- تحميل تصحيح CSS من مقطع JS مضاف، لتوافق صيغة التحديثات التي لا تسمح بأكثر من 8 ملفات.

## الاختبارات التي اجتازها نموذج Chromium
- مقاسات 320، 364، 390، 430 CSS px؛ عدم وجود تجاوز عرضي.
- ارتفاع البطاقة 46px وظهور الفهرس قبل 280px في النموذج.
- زر تنزيلات التفسير يحافظ على وظيفة P117؛ ثلاث النقاط تختفي في التفسير فقط وتعود في التلاوة.
- «آخر موضع» يفتح نفس آية الحالة المحفوظة في المحرك الأصلي.
- لا أخطاء JavaScript في نموذج الفحص، ولا تحكم في صوت أو طبعات القرآن.

## سبب عدم نشره كتحديث OTA نشط الآن
نسخة P117 APK تحتوي على فحص `requireTilawaOwnerApproval()` **داخل مستقبل التحديثات**؛ يقارن الملفات الثمانية المعتمدة في QA050 حرفيًا، ويطلب توقيع **Ed25519** بمفتاح موافقة المالك الخاص لأي تغيير فيها. وملف المفتاح الخاص المشفر **غير متاح في حزمة التوقيع Android RSA أو Library**. معرفة كلمة المرور وحدها لا تكفي لإنشاء التوقيع المطلوب. لا يجوز تعطيل القفل أو تحريك `release.json` إلى حزمة غير قابلة للتثبيت.

## آلية التفعيل عند توافر مفتاح الموافقة الخاص
1. اعتمد SHA256 لملف التحديث التراكمي (QA050 byte-identical prefix + P118 patch) وتأكد من خلوه من أي تعديل لمحركات التلاوة.
2. أنشئ بيانًا موقّعًا بـRSA للإصدار التالي مع استبقاء الملفات السبعة الأخرى حرفيًا.
3. أضف **موافقة قفل التلاوة Ed25519**، ذات تسلسل وملفات وبصمة وتاريخ انتهاء مطابقين لبروتوكول مستقبل P117، باستخدام المفتاح الخاص الأصلي؛ وألحق موافقة PR خاصة منفصلة لحارس GitHub.
4. تحقق من توقيعي RSA وEd25519، وSHA256 للملفات، واختبر تفعيل الحزمة فوق P117 مع عدم تراجع QA050 قبل النشر.
5. احفظ QA050 واسترجاعه، وانشر بيان `release.json` للمالك فقط.

**تحذير:** الملفات في `tafsir-ui/staging/p118/` ليست تحديثًا مثبتًا أو منشورًا للإنتاج. لا يوجد APK جديد ضمن هذا العمل.
