# BASAIR P118 / QA051 — تصحيح الخط والاختبار المباشر للشفرة الكاملة

**التاريخ:** 2026-11-10  
**النطاق:** staging فقط، لا تعديل لـQA050، لا نشر OTA، ولا إنشاء APK.

## الإصلاح المنجز

كشف تدقيق Chromium أن 9 تعليمات على الصورة `font:750 11.2px/1.25 inherit!important` لا تقبلها CSS؛ جرى تصحيحها إلى خاصيات `font-weight` و`font-size` و`line-height` و`font-family` منفصلة.

- الملف المستقل: `p118-tafsir-visual-match.css`.
- نسخة CSS المضمّنة داخل `p118-tafsir-visual-match.js`.
- تطابق المحتويين عند تجاهل السطر النهائي.
- ما تغير هو كتابة الخصائص الطباعية فقط، ولم تتغير معالجات التفسير أو محركات التلاوة.
- SHA-256 CSS المعدل: `64623bde653c12693224c6b4578e8599b1fe586e055f183316c3d4139e897614`.
- SHA-256 JavaScript المعدل: `82f8b8d08b97f478c8165f7bfbd23585bbda45c761e939f6c22e8922d4a06cb9`.

## الاختبارات المنفذة

1. **التحقق من CSS:** 9/9 خاصيات خط طويلة صحيحة من حيث الصياغة؛ لم يبقَ shorthand من الصيغة غير الصالحة؛ بقية صيغ `font` الأربع اختبرت بوساطة `CSS.supports` في Chromium وكانت صالحة.
2. **فحص JavaScript:** الشفرة الكاملة بعد التصحيح نجحت في التحليل النحوي؛ 46 محدد CSS جميعها مشروطة بنطاق تفسير `body.bq-tf117-index`.
3. **اختبار تشغيل JS الكامل في DOM صناعي داخل V8:** نجح تحميل CSS الكامل بطول 11544 حرفًا، وإنشاء شريط الأدوات مرة واحدة، وتحريك عناصر P117 الأصلية دون استبدال مستمعيها، وفتح البحث وآخر موضع، وضبط عنوان الفهرس، والرجوع وإعادة الدخول، وعدم المساس بعنصر وهمي للتلاوة. تقرير التشخيص: 0 أخطاء.
4. اختبار إعادة الإنتاج التفاعلي أُضيف في `test_p118_full_js_dom.mjs` ويمكن تشغيله عند وجود نسخة كاملة من المستودع بأمر:
   `node tafsir-ui/staging/p118/test_p118_full_js_dom.mjs`.
5. اختبار Chromium القديم 104/104 يخص الجزء الوظيفي المستخرج دون CSS الكامل، ولا يجوز نقله كدليل على النسخة الأخيرة.
6. فحص OWNER-LOCK في GitHub مطلوب عند كل التزام، وليس بديلًا عن تشغيل اختبار JS/Chromium/Android.

## حدود الأدلة

- لا اختبار Chromium لتصميم P118 الكامل على شاشات فعلية بعد.
- اختبار V8 استُخدم فيه DOM صناعي ليس محرك تخطيط ولا Android WebView.
- سكربت Node الجديد **مرفوع لإعادة التشغيل**؛ لم يدخل بعد في Workflow حارس GitHub، لأن ملفات الـWorkflows محمية ويستلزم تعديلها موافقة مالك مستقلة.
- لا اختبار تنزيل OTA على هاتف المالك، ولا تثبيت أو تشغيل Android من هذا التغيير.
