# P218 — ظل واحد فقط + «التحديث الشامل»

**المصدر:** تجربة المالك في 22 نوفمبر 2026 وصورتا المتابعة والتحديثات. ثبت ميدانيًا عمل متابعة الخطوط الآلية ووجود ظل متحرك صحيح مع ظل مستقل ثابت أضافه P215.

## الإصلاح النهائي المحدود

- **إزالة ملفَي P215 فقط من وصف وحدة التلاوة في التحديث الجديد**: `modules/tilawa/p215-digital-follow-shadow.js` و`.css`.
- إبقاء ملفات P214 السبعة عشر بالترتيب والبصمات الأصليين، بما فيها `p214-follow-route-adapters.js`. لا يمس الصوت، ولا تمرير الصفحات ولا خطوط المصحف ولا الطبعة الملونة.
- تُزال طبقة P215 الثابتة عند إعادة تحميل واجهة التطبيق بعد تفعيل الوحدة الجديدة؛ ويبقى تظليل المتابعة الأصلي الذي أكد المالك حركته على الهاتف.
- **لا يدّعي P218 إضافة توقيت لفظي جديد للكلمات**؛ التظليل الأصلي يتبع إمكانات المحرك المثبت كما هي.

## واجهة التحديث الشامل

- **مدخل وحيد باسم «التحديث الشامل»** في «المزيد»، مع إخفاء المداخل القديمة بمجرد تجهيز الواجهة؛ تظل وظائف P121/P197/P206/P207 الأصلية مركّبة وتستعاد بتعطيل الواجهة الجديدة.
- تبويبان فقط: «التحديث الجديد» و«الإصدارات المتاحة»؛ لا يوجد تبويب «الرجوع» المباشر.
- التحديث الجديد: رقم Seq، نوع التحديث، تاريخه، تفاصيله والأقسام المتأثرة؛ زر «تحميل التحديث» للتحديث الموقّع بنمط `notify`، ونسبة التنزيل الفعلية من P121، وزر إعادة فتح التطبيق بعد اكتمال التنزيل.
- عند فشل التنزيل يظهر «استئناف محاولة التحميل»، **ويُعاد تنزيل الملفات من البداية**: V695 لا يدعم HTTP byte-range resume. لا تُعرض نسبة تقديرية.
- الإصدارات: بطاقات Seq / رقم P، التاريخ، التفاصيل، نوع التغيير، أرقام الوحدات المحفوظة، وحالة المقارنة بين الأقدم والأحدث. لا يُسمح بتحديد نسخة غير محفوظة ومعتمدة أو فاشلة التوقيع.
- بعد اختيار إصدار معتمد يظهر زر «الرجوع إلى الإصدار المحدد» أو «الانتقال إلى الإصدار المحدد»، ثم شاشة تأكيد ثانية تُبيّن الرقم والمحتوى والتأثير. يتم التنفيذ فقط عبر `P206.restore()` الذي يعيد التحقق من توقيع الملف وملفاته ويحافظ على بيانات المستخدم.
- بانر P121 الأصلي «تحديث الآن» يفتح هذه الواجهة بدل تنزيل مباشر متزامن، دون تغيير محرك التحديث أو مفاتيحه.
- **الإشعار في التطبيق** فقط عند الفحص المتصل، وليس إشعار Android Push مضمونًا عند إغلاق APK كاملًا؛ ذلك يحتاج خدمة أصلية لم تثبت في V695.

## المرشحان الموقّعان
- `P218/Seq128`: وحدة التلاوة v245 (**17 أصلًا**) + وحدة التحديثات v218 (**7 أصول**)؛ RSA+Ed25519 الأصليان، وضع `notify`، إجمالي **185111 بايت**.
- `Seq129`: رجوع مستقل إلى ملفات P214 السبعة عشر مع تحديثات P206/P207 الخمسة في وحدات ذات أرقام أعلى (v246 وv219).
- لا APK جديد، ولا تغيير توقيع Android، ولا مساس بالملاحظات والمفضلة.
- **اختبارات JavaScript المعزولة: 39/39**. قبول Android الفعلي وظل المتابعة على الجهاز مطلوب قبل إعلان الاستقرار النهائي.
