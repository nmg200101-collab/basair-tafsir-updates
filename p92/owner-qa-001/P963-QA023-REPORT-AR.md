# بصائر القرآن — P96.3 / QA023 — ثبات متابعة الصفحة وظل التلاوة

**الحالة:** اجتازت الشيفرة الفحوص الآلية، ومرشح QA023 **غير موقّع وغير منشور** حتى اختبار المالك بموافقته.

## المرجع المحمي
- تطبيق V690/P92.3 مع تحديث المالك الموقّع QA022، تسلسل 22، قناة `owner-qa`.
- نجاح المالك في QA020 لعودة شكل خط المصحف، وفي QA021 لاستقرار الأصلية والتجويد الملون.
- لا تعديل النص القرآني أو محرك الصفحات أو السطر الأخير أو الطبعات أو التفسير أو الحفظ أو المكتبة.

## الملاحظة الميدانية
ذكر المالك أن الانتقال بين صفحات متابعة التلاوة يعمل ولكنه متقطع: أحيانًا يبدو مرور الصفحة سريعًا، وأحيانًا يغيب الظل تمامًا أو يظهر متأخرًا. لم يثبت بالاختبار على الهاتف بعد ما إذا كان تسارع الصفحة صادراً عن مُحرّك التمرير الأصلي أو عن انتقال DOM أو الصوت.

## التشخيص البرمجي المؤكد
1. `__BASAIR_P946_SHADE_SMOOTH__` يربط `tilawaAudio` عند فتح المتابعة فقط؛ إذا تبدل عنصر الصوت عند انتقال الصفحة لا يعيد ربط أحداث `timeupdate` تلقائيًا.
2. `paint()` يعيد `false` نهائيًا إذا لم توجد بطاقة الصفحة أو أسطرها وقت انتقال الصوت؛ ولا يتضمن إعادة محاولة محدودة بعد اكتمال رسم الصفحة.
3. قواعد P94.7 المخزنة داخل `p951-font-restored-header.css` تُخفي المؤشر `.bq916-reading-line` دائمًا. تُظهر النسخ الحالية ظلال الآية/الكلمة الأصلية `R95` عندما تتوفر علاماتها، لكن المؤشر البديل لا يظهر إذا غابت.
4. الكود السابق لا يمنح علامة الآية الأصلية أولوية إلا في حالات محددة لتوقيت الصوت، حتى لو ظهرت العلامة فعليًا على الصفحة الحالية.

## إصلاح QA023 المعزول
- ملف JavaScript `p963-follow-page-shade.js`: يحافظ على جميع أقسام QA022، ويعدل فقط وحدة المتابعة البصرية الأخيرة.
- عند بدء انتقال الصفحة تُخفى إشارة الصفحة السابقة فورًا، ثم يُنتظر رسم بطاقة الصفحة الجديدة عبر إعادة محاولات **محدودة بحد أقصى 9 محاولات** بفواصل 160ms؛ بدون مراقبة DOM شاملة أو تغيير التمرير.
- حارس خفيف كل 750ms يعمل فقط أثناء المتابعة الصوتية؛ يكشف استبدال عنصر الصوت ويعيد ربط الأحداث دون تشغيله أو إيقافه.
- إذا وُجدت علامة الآية/الكلمة الأصلية بالفعل فهي المفضلة؛ ويختفي المؤشر التقريبي.
- في غياب العلامة الأصلية مع توفر بطاقة وأسطر المصحف وبيانات مدة الصوت، يمكن إظهار **مؤشر سطر أخضر خفيف تقريبي**؛ ليس تزامنًا دقيقًا للكلمات أو الآيات ولا يجب تقديمه للمستخدم على هذا الأساس.
- ملف CSS `p963-follow-page-shade.css`: يحتفظ بكامل CSS المعتمد ويضيف في نهايته قواعد محدودة لإظهار المؤشر التقريبي في **متابعة التلاوة المطبوعة فقط** وبشرط أن يكون خيار التظليل مفعّلًا. يحترم إيقاف التظليل والوضع الليلي والتخفيف الحركي.
- لا تُسند أبدًا أوامر `audio.play`/`pause` أو إزاحة صفحة أو `scrollTo` أو تعديل `font-size`.
