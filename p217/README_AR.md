# P217 — سجل الإصدارات الموثّقة محليًا (تجهيز، غير منشور)

## المنجز
- مُحوّل مستقل `__BASAIR_P217_VERIFIED_HISTORY__` يعرض آخر **6 نسخ معتمدة** مع نسخة واحدة بانتظار الاعتماد لدى P206، وليس قائمة إصدارات وهمية من أرقام GitHub.
- يفحص بيان كل نسخة بتوقيع RSA/Ed25519 عبر `P206.verify()`، ثم يتحقق من مطابقة الملفات والبصمات عبر `P206.matches()`.
- يميّز الإصدارات الأقدم والأحدث حسب أرقام الوحدات **النشطة**، لا رقم أعلى تسلسل وحده.
- يرفض الاستعادة عند غياب توقيع صحيح أو ملفات مطابقة، أو اعتماد المالك، أو حالة جهاز مؤكدة، أو عند وجود تجربة تفعيل جارية.
- عند تأكيد الرجوع مرتين في P216 تُعاد سلامة النسخة وتُفوّض العملية حصريًا إلى `P206.restore()`، وهو يحتفظ بمحرك التحديث الموقّع.
- لا يحمل أي ملفات من الإنترنت، ولا يعيد بناء ملفات تاريخية غير محفوظة، ولا ينشئ APK أو يعيد ضبط بيانات المستخدم.

## التجهيز والتوافق
- مسار JS الجديد: `modules/updates/p217-verified-history.js`.
- P216 يفضّل P217 عندما يكون متاحًا، ثم يعود إلى P206 الحالي إذا غاب أو لم يُفعّل.
- P217 يضاف بعد أصول P216 السبعة، مع الاحتفاظ بالبصمات الموقّعة لخمس ملفات التحديث الأصلية دون تعديل.
- الخطتان في `p216/report/P216_UNSIGNED_MODULE_PLAN.json` و`p217/report/P217_UNSIGNED_MODULE_PLAN.json` **غير موقعتين**؛ الأرقام Seq128 وSeq130 مقترحة فقط.
