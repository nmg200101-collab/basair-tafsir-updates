# P209 — فحص الإقلاع بالصفحة الأصلية في APK V695

- استُخرجت أصول `assets/www` (1691 ملفًا) مؤقتًا من ملف V695 المقدم من المالك بغرض الفحص المحلي فقط، دون رفعها إلى مستودع GitHub أو تضمينها كلها في الأرشيف المقدم.
- حُمّلت صفحة `index.html` الفعلية (حوالي 4.6 م.ب) في Chromium باستخدام `page.set_content` وإعادة تقديم ملفات الموارد المطلوبة محليًا. ظهرت الواجهة الرئيسية، وتأكد وجود `window.__BASAIR_B345_SEQUENCE__` و`window.__BASAIR_PRINT_FOLLOW_100__` و`window.BasairUniversalOTA`.
- **قيد جوهري:** متصفح الاختبار يعمل في أصل افتراضي `about:blank` بدل أصل Android WebView الحقيقي، لذلك منع صلاحيات `localStorage` وIndexedDB، وظهرت أخطاء تهيئة إضافية. لم نتمكن من اعتماد تشغيل مباشر للتلاوة عبر ملف APK كامل، ولا نحتسب هذا الفحص ضمن اختبارات القبول الناجحة الـ84.
- عند محاولات تحميل الصفحة عبر `file://` أو HTTP محلي أو نطاق محاكى، منعت سياسة المتصفح في بيئة العمل هذه الملاحة، لذا ليس صحيحًا الادعاء بأننا اختبرنا WebView الحقيقي على الهاتف.
- مصدر اختبار تقدم الصوت ولمس الآيات هو **ملفات JS الأصلية ووحدات Hit Map الفعلية المدروسة من APK** مع محاكاة DOM وB345. حزمة P209 غير موقعة وغير منشورة، ويمنع دمجها في بيان `owner-qa/release.json` قبل اختبار واقعي مستقل.
